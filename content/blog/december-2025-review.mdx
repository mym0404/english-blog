## 말해보카(ePop)

![image.png](https://cdn.jsdelivr.net/gh/mym0404/image-archive@master/20260106141731419.png)

I have been using this app since December 2024. It's sort of a simple vocabulary studying application for Koreans. The core learning algorithm comes from Anki. It has users practice with [spaced-repetition](https://en.wikipedia.org/wiki/Spaced_repetition) quizzes.

Over a year, I've gotten a huge number of words. Getting more high level of words, the harder words, idioms and phrasal verbs have appeared.

ePop is a good example of making learning something into a game. In my previous job, we were also inspired by ePop's UX and learning system.

I've been using not only the word-learning section but also the listening section. It lets me listen to a short sentence and write it down. I couldn't do it initially, however after about a week, I managed to distinguish some common difficult pronunciations.

I don't know if it is really helpful for listening skills. Although, I'm going to try that kind of studying too.
