## 인사 & 소개

일상에서 가장 많이 사용하는 인사말입니다.

| 영어 | 한국어 | 예문 |
|------|--------|------|
| Hello | 안녕하세요 | Hello, how are you? |
| Goodbye | 안녕히 가세요 | Goodbye, see you later! |
| Thank you | 감사합니다 | Thank you for your help. |
| Sorry | 죄송합니다 | I'm sorry for being late. |
| Please | 부탁합니다 | Please help me. |

## 감정 표현

### 긍정적 감정

```
😊 Happy - 행복한
😁 Excited - 신나는
😌 Relaxed - 편안한
🥰 Grateful - 감사하는
😎 Confident - 자신감 있는
```

**예문**:
- I'm so **happy** to see you!
- She feels **excited** about the trip.
- He's **grateful** for your support.

### 부정적 감정

```
😢 Sad - 슬픈
😰 Anxious - 걱정되는
😠 Angry - 화난
😫 Tired - 피곤한
😔 Disappointed - 실망한
```

**예문**:
- I feel **sad** today.
- Don't be **angry** with me.
- She was **disappointed** with the result.

<Callout type="info">
  💡 **Tip**: 감정 표현은 "I feel..." 또는 "I'm..."과 함께 사용합니다.
  - I feel happy.
  - I'm excited.
</Callout>

## 날씨 표현

날씨에 대해 이야기할 때 자주 사용하는 표현들입니다.

### 맑은 날씨
- **Sunny** ☀️ - 맑은
- **Clear** - 청명한
- **Bright** - 밝은

### 흐린 날씨
- **Cloudy** ☁️ - 흐린
- **Overcast** - 잔뜩 흐린
- **Gloomy** - 우중충한

### 비/눈
- **Rainy** 🌧️ - 비 오는
- **Snowy** ❄️ - 눈 오는
- **Stormy** ⛈️ - 폭풍우 치는

**회화 예시**:
```
A: How's the weather today?
B: It's sunny and warm!

A: What's the weather like?
B: It's cloudy and a bit cold.
```

## 시간 표현

### 시간 관련 단어

| 영어 | 한국어 |
|------|--------|
| Morning | 아침 |
| Afternoon | 오후 |
| Evening | 저녁 |
| Night | 밤 |
| Dawn | 새벽 |
| Noon | 정오 |
| Midnight | 자정 |

### 요일

- Monday (월요일) - Mon.
- Tuesday (화요일) - Tue.
- Wednesday (수요일) - Wed.
- Thursday (목요일) - Thu.
- Friday (금요일) - Fri.
- Saturday (토요일) - Sat.
- Sunday (일요일) - Sun.

<Callout type="warn">
  ⚠️ **주의**: 영어에서 요일과 월은 항상 대문자로 시작합니다!
  - ✅ Monday
  - ❌ monday
</Callout>

## 음식 관련

### 식사
- **Breakfast** - 아침 식사
- **Lunch** - 점심 식사
- **Dinner** - 저녁 식사
- **Snack** - 간식

### 맛 표현

- **Bitter** - 쓴
- **Sweet** - 달콤한
- **Salty** - 짠
- **Sour** - 신
- **Spicy** - 매운

**예문**:
```
This pizza is delicious!
The coffee is too bitter.
I like sweet desserts.
```

## 학습 방법

### 1. 하루 10개씩 암기

한 번에 많은 단어를 외우려 하지 말고 매일 10개씩 꾸준히 암기하세요.

### 2. 예문과 함께 학습

단어만 외우지 말고 항상 예문과 함께 학습하세요.

### 3. 복습은 필수

3일, 7일, 14일 주기로 복습하여 장기 기억으로 만드세요.

### 4. 실생활에 적용

배운 단어를 실제로 사용해보세요. 영어 일기를 쓰거나 대화에 활용하세요.
