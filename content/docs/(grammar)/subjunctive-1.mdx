가정법에 대해서 공부해보자. 여러가지 가정법 문법이 있지만, 기본적으로 if 를 사용하는 가정법들에 대해서 먼저 정리한다.

---

총 5가지 타입을 정리할 것이고 다음과 같다.

- **일반 조건문(Zero conditional)**: If 현재, 현재
	- 만약 ~한다면 (항상) ~한다.
- **가정법 현재(First conditional)**: If 현재, will/can/may + V
	- 만약 ~한다면 ~할 것이다. (가능한 미래)
- **가정법 과거(Second conditional)**: If 과거, would/could/might + V
	- (지금) 만약 ~라면 ~할 텐데
- **가정법 과거완료(Thrid conditional)**: If had p.p., would/could/might + have p.p.
	- (그때) 만약 ~했더라면 ~했을 텐데
- **혼합 가정법(Mixed conditional)**: If had p.p., would/could/might + V
	- 그때 ~했었다면 지금 ~할 텐데

# 1. 일반 조건문 (Zero conditional)

> If we go to the hospital, we don't have to go to work.
> 
> 만약 병원에 간다면, 출근은 안해도 돼.

일반 조건문은 일반적인 조건들에 대한 설명을 할 때 유용하다. 항상 성립하는 사실 / 규칙 / 습관을 말한다.

구조는 다음과 같고. **~하면(항상) ~한다.** 라는 의미정도이다.

> If 현재, 현재

## 예시

- If you heat ice, it melts. 얼음에 열을 가하면 녹는다.
- If I drink coffee at night, I can't sleep well. 난 밤에 커피를 마시면 잠에 잘 못든다.
- If you press this button, the machine starts. 이 버튼을 누르면 기계가 작동한다.

# 2. 가정법 현재 (First conditional)

>If it rains, I won't go shopping tomorrow.
>
>만약 비가 온다면, 난 내일 쇼핑을 가지 않을거야.

가정법 현재는 아직 일어나지 않은 일이지만 **지금이나 나중에 ~ 한다면 나중에 ~ 될 것이다**를 표현하는 데 사용된다. 조건이 충족되면 일어날 가능성이 높은 결과를 의미한다.

경고, 제안, 안내문에 쓰이기도 한다.

**만약 ~한다면, ~할 것이다.** 정도의 의미로 쓰인다.

구조는 다음과 같다.

>If 현재, will/can/may + V

## 예시

- If you finish early, you can leave. 너가 빨리 끝낸다면, 가도 돼.
- If you get into this area, you might die. 이곳에 진입하면 죽을 수도 있습니다.
- If you don't hurry, you might miss the train. 서두르지 않는다면 기차를 놓칠거야.

# 3. 가정법 과거 (Second conditional)

> If I could type faster, I would write my essay first.
> 
> 내가 만약 타자를 빨리친다면, 에세이부터 썼을텐데.

가정법 과거는 **현재 사실을 반대로 가정**하는 문법이다. 

구조는 다음과 같다.

> If 과거, would/could/might + V

**(지금) 만약 ~라면, ~할 텐데** 정도의 의미로 쓰인다.

> [!INFO]
> 주의할 점은 대명사가 어떤것이든 간에 be동사는 `were`를 사용한다는 것이다.
>
> If I were … (O)
> If I was … (X)

앞의 절에서 과거형을 쓴다고 해서 이를 **과거 시간으로 오해하는 것은 안된**다.
과거 시간보다는 **비현실성(거리감)** 을 의미하는 역할이 크다.

## 예시

- If I were 180 cm, I would play basketball. 내가 키가 180였다면 농구를 했을텐데.
- If I were you, I would apologize to him. 내가 너였다면 그에게 사과했을걸.
- If I had money, I could buy the new running shoes.

# 4. 가정법 과거완료 (Third conditional)

> If I had woken up earlier, I wouldn't have missed lunch.
> 
> 내가 더 일찍 일어났다면, 점심 먹을수 있었을텐데.

가정법 과거완료는 이미 과거에 끝났던 일에 대한 가정이다.

과거 사실과 반대이고 **그때 ~했더라면 ~했을 텐데** 의 의미로 쓰인다.

과거 사건에 대한 후회나 평가를 의미하고 "그때 다른 선택을 했더라면 결과가 달랐을 것"을 말하기 위해서 쓰인다.

구조는 다음과 같다.

> If had p.p., would/could/might have p.p.

## 예시

- If I had studied hard, I could have passed the exam. 내가 공부를 더 열심히 했었다면 시험에 통과할 수 있었을텐데.
- If you had enlisted the army earlier, you would have been discharged last year. 너가 입대를 더 빨리했더라면 작년에 전역했을텐데.
- If we had gotten married in Korea, we would have cost more money. 우리가 한국에서 결혼했었다면 돈이 더들었을거야.

# 5. 혼합 가정법 (Mixed Conditional)

> If I had bought a bigger backpack yesterday, I could pack all of these things.
> 
> 만약 어제 더 큰 배낭을 샀었다면, 지금 이거 다 담을 수 있었을텐데.

혼합 가정법은 **과거 원인이 현재 결과가 된 상황**을 표현하기 위해 사용된다.

과거의 사건이 지금 상태에 영향을 주는 상황이고 뉘앙스는 **그때 ~했더라면 지금 ~할 텐데** 정도이다.

구조는 다음과 같다.

> If had p.p., would/could/might + V (현재 결과)

## 예시

- If I had slept earlier, I would feel better now. 만약 일찍 잤더라면 지금 좀 컨디션 괜찮을텐데.
- If you had gotten a job, you wouldn't be homeless. 너가 직업을 더 일찍 가졌더라면 너가 지금 길바닥에 나앉지 않았을텐데.
- If we hadn't missed the flight, we would be home now. 우리가 비행기를 안놓쳤더라면 지금 집에 있을텐데.
- If I had started studying English grammar earlier, I wouldn't need to run this blog now. 내가 영어 문법 공부를 일찍 시작했더라면, 지금 이 블로그를 운영하고있지 않을텐데. 

# Outro
