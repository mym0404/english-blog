# 1. wish 가정법

말 그대로 동사 `wish`를 써서 가정을 하는 용법이다.

세 가지로 나뉜다.

## wish + S + V-ed

**난 ~가 ~라면 좋겠어** 느낌으로 쓴다.

현재와 반대인 사실에 대해 사용한다.

- I **wish** you **were** my brother. 난 네가 내 형제이면 좋겠어.
- I **wish** I **knew** the solutions for that contest. 난 그 경연대회의 해답을 다 알았으면 좋겠어.

:::info
역시나 주의할점은 과거형이 쓰인다고 시간적으로 과거를 의미하는게 아니라는 점이다. **영어에서는 거리감이나 공손함 등을 표현하기 위해 과거형, 더 나아가 과거완료를 사용할 수 있음**을 알자. 
:::

## wish + S + had p.p.

좀 더 과거 + 거리감을 가미해서 **난 ~가 ~라면 좋았겠어** 라는 느낌으로 쓴다.

과거에 일어났던 사건이 반대라면 어떨까 가정하는 용법이다.

- I **wish** I **had studied** hard. 공부를 더 열심히 했으면 좋았을걸.
- I **wish** Tim **had gone** to a doctor earlier. 팀이 더 빨리 병원에 갔으면 좋았을텐데 

## wish + S + would + V

**미래에 대한 소망이나 불만, 짜증을 표현**하기 위해 사용한다.

:::error
주의할 점은 자기 자신을 주어로는 잘 사용하지 않는다는 점이다. (의지 표현 충돌)
:::

- I **wish** it **would** **stop** raining 아 비좀 그쳤으면 좋겠네.
- I **wish** he **would call** me.  아, 그가 나한테 전화좀 했으면 좋겠네


# 2. if only 가정법

`wish`보다 강한 느낌이다.

뉘앙스는 **아... 제발 ~라면** 처럼 강하다. 더 감정적이다.

자주 문장이 단독으로 사용된다.

wish 가정법과 3가지 용법에 대한 문법이 모두 같다. `S + wish`냐, `If only`냐의 차이라고 볼 수 있겠다.

:::error
주의할 점은 `if only + S + would + V` 에서는 자기 자신을 주어로는 잘 사용하지 않는다는 점이다. (의지 표현 충돌)
:::

예문만 몇개 보자.

- **If only** I **enlisted** as an army software developer. 아, 내가 육군 개발병이였다면,
- **If only** I **had studied** hard. 아, 공부좀 열심히 할껄
- **If only** you **would pick up** some snacks. 너가 제발 과자좀 사왔으면 한다.


# 3. as if / as though 가정법

일단 `as if = as though`이다.

`wish, if only` 같은 세 가지 용법을 가진다(과거, 과거완료, would).

**마치 ~인 것처럼** 같은 뉘앙스로 쓰인다.

따라서 **사실이 아니거나** 그럴 **가능성이 매우 낮은 것**을 가정한다.

> [!WARNING] Warning
> `as if`이후에 현재형인 동사도 올 수 있다. 이 경우 실제로 사실이거나 가능성이 있다고 보는 경우로 해석된다.


말하는 태도나 인상, 상황 묘사에 많이 사용된다.

> [!TIP] Tip
> *마치 ~인 것처럼* 이라는 의미 때문에 `like`이랑 뭐가 다른가라고 생각할 수 있다.
>
`as if`는 가정이고 `like`은 비유이다. `as if`는 실제 사실이 아닌걸 가정하기 때문에 의미가 다르다.
>
> - He acts **as if** he **knew** everything. 다 **아는 것 마냥**(실제가 아님) 행동했다.
> - He dances **like** a butterfly. 한마리의 나비**처럼** 춤췄다.
>
`as if`는 접속사로 뒤에 절만 오고 `like`은 전치사, 접속사 모두 가능하다. 따라서 뒤에 절이나 명사 모두 올 수 있다.


`as if + S + would` 는 **의지, 태도, 고집을 말할 때만** 쓰인다.

`as if + S + be going to`는 직설적인 미래를 가정할 때 쓰인다. (~할 것처럼 보인다.)

- He talks as though he was a dancer. 그는 마치 그가 댄서였던 것처럼 말했다.
- She spoke as if she had met him before. 그녀는 마치 예전에 그를 만나보기라도 한것마냥 얘기했다.
- It looks as if it is going to rain. 비가 올 것처럼 보인다. (실제로 올 수도 있음)
- He talks as if he would never admit his mistake. 걔는 마치 절대 자기 고집을 꺾을 생각이 없는것처럼 마랗네.

:::tip
`as if + S + will`은 쓰일 수 없는데, `will`은 강한 의지를 나타내는데 `as if`자체가 마치 ~ 인것같다는 뉘앙스여서 의미가 충돌된다.
:::

# 4. Would rather / Would prefer

정중한 선택, 선호를 표현한다. 회화와 문어에서 모두 흔하다.

문법은 다음과 같다.

>would rather + S + V-ed
>
>would prefer + S + V-ed

주의할 점은 `would rather + V` 와 `would prefer + to-V` 와는 다르다는 점이다. 저것들은 ~를 하는걸 좋아한다라는 의미이고 이건 가정이다.

> I'd rather you stayed here
> 
> 너가 여기 있었으면 해.

> I'd prefer you didn't tell anyone.
> 
> 아무한테도 말 안했으면 좋겠어요. 

# 5. It's time / It's about time

**지금쯤이라면/이제야말로 ~를 해야하는데** 라는 뉘앙스이다. 불만스러운 상황을 표현할 수 있다.

문법은 다음과 같다.

> It's (about) time + S + V-ed

>It's time you went to bed.
>
>지금쯤이면 자야할 시간 아니니?

>It's about time he apologized.
>
>이제야말로 그가 사과할때야.

# 6. that절 현재 가정법 (Mandative Subjunctive)

**요구·명령·제안·필요**를 나타낼 때 쓰는 가정법이다.  
특히 **공식 문서, 뉴스, 논문**에서 매우 자주 등장한다.

문법은 다음과 같다.

> V/Adj + that + S + V (동사원형)

### 자주 쓰이는 동사·형용사
- suggest, recommend, insist, demand, require  
- important, necessary, essential  

> I suggest that he go home.  
> 그가 집에 가는 게 좋겠다.

> It is important that everyone be present.  
> 모두가 참석하는 것이 중요하다.

# 7. should 가정법

**혹시 ~한다면 / 만약 ~할 경우**  

→ 가능성은 낮지만 배제하지 않는 상황  
격식체에서 자주 사용된다.

문법은 다음과 같다.

> If + S + should + V, S + V  

  
> If you should need help, call me.  
> 혹시 도움이 필요하면 전화해.

> If he should arrive early, let me know.  
> 그가 혹시 일찍 도착하면 알려줘.

# 8. 가정법 도치 (Inversion)

**if를 생략하고 조동사를 문두로 이동**

→ 의미는 동일, **격식·문어체**

문법은 다음과 같다.

`Had`, `Were`, `Should`가 의문문이 아닌데도 문장의 젤 앞에 나온다면 가정법이 도치되었구나 라고 생각할 수 있다.

`Had`는 가정법 과거완료, 혼합가정법의 구조인 `If S had p.p.,` if 절이 도치된 형태이다.

`Were`는 `If I were you,` 같은게 도치된 것이다.

`Should`는 should 도치법인 `If you should need help,` 같은게 도치된 문장이다.
  
- **Had** + S + p.p., S + would (have) p.p.  
- **Were** + S + (to), S + would V  
- **Should** + S + V, S + V  

> Had I known the truth, I would have acted differently.  
> 진실을 알았더라면 다르게 행동했을 것이다.

> Were I you, I would quit the job.  
> 나라면 그 일을 그만두겠다.

> Should you need any help, please contact us.  
> 도움이 필요하시면 연락 주세요.
